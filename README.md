# Proyecto de ejemplo con skills de Emil Kowalski

Las skills están en `.claude/skills/`, copiadas desde https://github.com/emilkowalski/skills (licencia en `LICENSE-skills`).

Para usarlas en un proyecto real, copia la carpeta `.claude/skills/` a la raíz de tu repositorio.

## MedInfo

En [`medinfo/`](medinfo/) está **MedInfo**, una app móvil (Expo / React Native) para consultar información de medicamentos
a partir de fuentes oficiales (CIMA-AEMPS y openFDA) y comprobar interacciones. Ver [medinfo/README.md](medinfo/README.md).
